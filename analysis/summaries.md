# Analysis Summaries

Periodic/cycle-level analyses go here. This file is descriptive, not raw data.

Possible analyses once enough observations exist:
- bodyweight trend and rate of gain;
- calorie/protein adherence;
- performance trends by exercise;
- actual training frequency;
- set volume by muscle;
- RIR and recovery patterns;
- repeated fatigue or stagnation signals;
- response before/after program changes.

No conclusion should be presented as a trend when evidence is only a single noisy observation.

# Decision Ledger

Permanent record of material changes to training, tracking or nutrition targets.

## Rule
Each decision records:
- date;
- old → new state;
- evidence/reason;
- hypothesis;
- affected program version when applicable;
- what would make us reconsider it.

Do not rewrite old decisions when later evidence changes our interpretation. Add a new decision.

---

## 2026-10-02 — Initial system

**Change:** Establish PPL-001 and structured daily/set-level tracking.  
**Reason:** Create a measurable baseline instead of relying on remembered loads/repetitions.  
**Hypothesis:** Consistent set-level performance, bodyweight, nutrition, sleep and recovery data will allow future training and calorie changes to be based on trends rather than isolated sessions.  
**Reconsider:** Exercise selection, volume, frequency, RIR and nutrition targets after sufficient real observations accumulate.

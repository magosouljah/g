# Decision Ledger

Permanent record of material changes to training, tracking or nutrition targets.

## Rule
Each decision records:
- date;
- old → new state;
- evidence/reason;
- hypothesis;
- affected program version when applicable;
- what would make us reconsider it.

Do not rewrite old decisions when later evidence changes our interpretation. Add a new decision.

---

## 2026-10-02 — Initial system

**Change:** Establish PPL-001 and structured daily/set-level tracking.  
**Reason:** Create a measurable baseline instead of relying on remembered loads/repetitions.  
**Hypothesis:** Consistent set-level performance, bodyweight, nutrition, sleep and recovery data will allow future training and calorie changes to be based on trends rather than isolated sessions.  
**Reconsider:** Exercise selection, volume, frequency, RIR and nutrition targets after sufficient real observations accumulate.

## 2026-10-06 — Formalize direct abdominal work

**Change:** PPL-001 → PPL-002. Add 2 sets of Abs Crunch at the end of Push. Historical rows remain on their original program version.  
**Reason:** Direct abdominal work was absent from the written routine but was performed in the first Push session and is intended to be a regular part of the program rather than an improvised exercise.  
**Hypothesis:** Keeping direct abdominal work explicitly prescribed will improve consistency, trackability and abdominal development without materially disrupting recovery.  
**Affected program version:** PPL-002.  
**Reconsider:** During the planned broader routine review, or earlier if abdominal work meaningfully interferes with performance or recovery.

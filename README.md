# g

Repo simple para llevar mi entrenamiento con el objetivo principal de ganar mucha masa muscular y priorizar mis músculos según `knowledge/profile.md`.

## Estructura

- `knowledge/` = cosas que sabemos de verdad. Ahora solo contiene mi perfil. Si yo aporto un estudio, paper o regla que quiera usar, se puede guardar aquí.
- `program/` = referencia de ejercicios, volumen, RIR y descansos. No obliga a seguir una rutina rígida día por día.
- `copy-paste/` = material operativo cuando sea útil; no obliga a reportar diariamente.
- `log/` = historial de lo que realmente pasó. No se reescribe para que coincida con cambios futuros.
- `analysis/` = conclusiones reales obtenidas de datos suficientes y revisiones periódicas.

## Forma de trabajar

El entrenamiento es flexible. No hace falta decidir la rutina completa con el chat antes de ir al gimnasio ni seguir PPL de forma rígida.

Yo entreno y después paso lo que hice, ya sea ese mismo día o varios días juntos. Los datos se registran en `log/`.

Cuando pida analizar un entrenamiento, el análisis debe actuar como entrenador: comparar contra el historial, las prioridades y el objetivo de hipertrofia y responder de forma concisa. Solo señalar los cambios que realmente importan (normalmente 1-3), por ejemplo:

- falta volumen o frecuencia en un músculo prioritario;
- sobra trabajo en un músculo de menor prioridad;
- conviene subir, mantener o bajar carga según reps, RIR y técnica;
- hay demasiada fatiga o trabajo al fallo;
- el descanso entre sesiones o series parece insuficiente o excesivo;
- un ejercicio o músculo está progresando o estancándose.

No hace falta preguntar durante el entrenamiento qué ejercicio hacer a continuación. El control principal es retrospectivo.

## Sistema conectado

### 1. Registro continuo

Registrar cuando haya datos:

- entrenamiento: ejercicio, carga, reps, RIR, descanso y notas relevantes;
- alimentación: calorías/proteína y otros datos disponibles;
- peso corporal y medidas cuando existan.

No es obligatorio mandar datos todos los días. Se pueden registrar varios días juntos.

### 2. Análisis bajo demanda

Cuando yo diga que analices un entrenamiento o periodo, revisar en conjunto:

- volumen y frecuencia por músculo;
- prioridad muscular;
- progresión de carga/reps/RIR/técnica;
- fatiga y recuperación;
- distribución del esfuerzo hacia el objetivo de ganar masa.

La respuesta debe ser corta y accionable. No enumerar problemas irrelevantes solo por completar una lista.

### 3. Auditoría semanal

Idealmente una vez por semana, preferentemente el domingo porque es día de descanso, revisar todos los datos disponibles de la semana.

La auditoría debe cubrir:

- estado general: 🟢 bien / 🟡 ajustar / 🔴 problema;
- tendencia de peso corporal si hay datos;
- alimentación/calorías/proteína si hay datos;
- progresión en ejercicios comparables;
- volumen y frecuencia de músculos prioritarios frente a músculos de menor prioridad;
- recuperación/fatiga;
- máximo 1-3 decisiones importantes para la semana siguiente.

Si faltan datos para juzgar algo, decirlo en vez de inventarlo.

### 4. Revisión física periódica

Aproximadamente cada 4 semanas, si hay datos, revisar fotos y/o medidas junto con peso y rendimiento. El criterio final no es solo levantar más peso: es ganar masa muscular y mejorar físicamente de acuerdo con las prioridades del perfil.

## Principios

1. El objetivo manda; una rutina escrita es una herramienta, no el objetivo.
2. `knowledge/profile.md` define las prioridades actuales.
3. `program/` sirve como referencia y marco de progresión, no como obligación rígida diaria.
4. `log/` guarda hechos, no planes ni suposiciones.
5. No inventar datos faltantes.
6. No confundir mover más peso sacrificando técnica con progreso real.
7. No agregar volumen automáticamente: primero considerar estímulo, progresión, prioridad y recuperación.
8. No crear archivos o texto "por si acaso". Si no aporta algo necesario, es ruido.

# g

Repo simple para llevar mi entrenamiento.

## Estructura

- `knowledge/` = cosas que sabemos de verdad. Ahora solo contiene mi perfil. Si yo aporto un estudio, paper o regla que quiera usar, se puede guardar aquí.
- `program/` = fuente de verdad de la rutina actual: qué ejercicios y cuántas series se hacen.
- `copy-paste/` = copia operativa del programa para rellenarla después de entrenar y mandarla al chat.
- `log/` = historial de lo que realmente pasó. No se reescribe para que coincida con cambios futuros.
- `analysis/` = solo existe cuando haya una conclusión real obtenida de datos suficientes. No se crean análisis por adelantado.

## Reglas

1. No agregar conocimiento que yo no haya dado o aportado.
2. `program/` manda; `copy-paste/` debe reflejarlo.
3. `log/` guarda hechos, no planes ni suposiciones.
4. No inventar datos faltantes.
5. No crear archivos o texto "por si acaso". Si no aporta algo necesario, es ruido.

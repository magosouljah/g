# Progression Rules — PPL-001

## Default: double progression
For each exercise, keep the prescribed load while accumulating reps inside its target range with the prescribed RIR and repeatable technique.

Increase load when all work sets reach the top of the rep range without exceeding the effort target. Use the smallest practical increase available, then rebuild reps within the range.

## Do not reward bad reps
A rep only counts for progression if technique and ROM remain sufficiently consistent to compare with prior sessions.

## If performance falls
One poor exposure normally causes no program change. Keep the prescription and inspect sleep, nutrition, execution, RIR accuracy and recovery. React to repeated trends rather than noise.

## Volume
Do not automatically add sets because recovery feels easy. Increase or decrease volume only when repeated performance/recovery data and the target muscle's priority justify a test.

## Failure
Compounds are normally kept around 1–2 RIR. Isolation work can approach failure more closely; a final set may reach 0 RIR when safe and useful. Failure is a tool, not a requirement.

## Deload / fatigue intervention
Do not schedule automatic deloads by calendar. Consider reducing fatigue when several exposures show meaningful performance decline and/or persistent recovery problems, especially when they cannot be explained by isolated sleep/nutrition disruptions.

## Rest intervals
Preserve set quality. Typical starting point: 3–4 min for demanding compounds, 2–3 min for isolations. Extend rest when cardiorespiratory recovery or local fatigue would otherwise materially reduce the next set.
